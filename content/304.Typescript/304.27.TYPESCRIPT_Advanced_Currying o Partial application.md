## Que és
És una tècnica de programació funcional que **consisteix a transformar una funció que accepta múltiples arguments en una seqüència de funcions, cadascuna de les quals accepta només un argument**. 

També es coneix com a **Partial application** perquè permet "precarregar" alguns arguments d'una funció i retornarne una de nova amb els arguments restants encara per especificar.
## Exemple
Suposem que tenim una funció normal que suma tres números:
```typescript
function add(a: number, b: number, c: number): number {
    return a + b + c;
}
```
Podem transformar aquesta funció en una funció currificada:
```typescript
function curriedAdd(a: number) {
    return (b: number) => {
        return (c: number) => {
            return a + b + c;
        };
    };
}
```
Ara podem utilitzar `curriedAdd` d'aquesta manera:
```typescript
const add5 = curriedAdd(5);  // Precarreguem 'a' amb 5
const add5And3 = add5(3);    // Precarreguem 'b' amb 3
const result = add5And3(2);  // Finalment afegim 2 com a 'c'

console.log(result); // Sortida: 10
```
Aquest procés és útil quan es treballa amb funcions complexes o reutilitzables, especialment en contextos funcionals.

## Tipus integrant Parameters a TypeScript
Quan es treballa amb currying o aplicació parcial, és comú necessitar extreure els arguments d'una funció. TypeScript proporciona una utilitat integrada anomenada [[./304.11.TYPESCRIPT_Built-in_Parameters|Parameters]], que pot ser molt útil. 
Això ens pot ajudar a definir funcions currificades més robustes
### Currying automatitzat amb Parameters
Podem crear una funció genèrica per currificar qualsevol funció utilitzant Parameters i altres utilitats tipus:

```typescript
type Curried<T> = T extends (...args: [infer A, ...infer Rest]) => infer R
    ? (arg: A) => Curried<(...args: Rest) => R>
    : T;

function curry<F>(fn: F): Curried<F> {
    return function curried(...args: any[]) {
        if (args.length >= fn.length) {
            return fn(...args);
        }
        return (...nextArgs: any[]) => curried(...args, ...nextArgs);
    } as Curried<F>;
}

// Exemple:
const curriedMultiply = curry(multiply);
const multiplyBy2 = curriedMultiply(2);
const result = multiplyBy2(5); // 10
```
Aquest exemple utilitza tipus avançats i currying per crear funcions flexibles i reutilitzables.
## Beneficis del Currying
- Reutilització de codi: Permet crear versions personalitzades de funcions genèriques.
- Funcions més clares: Millora la llegibilitat quan es treballa amb funcions que tenen molts arguments.
- Composabilitat: És essencial en paradigmes funcionals per a la creació de cadenes de transformacions.
