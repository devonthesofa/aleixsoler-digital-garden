Aquesta utilitat retorna un tuple amb els tipus dels arguments d'una funció.

### Exemple amb `Parameters`
```typescript
function multiply(a: number, b: number): number {
    return a * b;
}
```
Podem utilitzar Parameters per obtenir els tipus dels seus arguments:

```typescript
type MultiplyArgs = Parameters<typeof multiply>; // [number, number]
```
