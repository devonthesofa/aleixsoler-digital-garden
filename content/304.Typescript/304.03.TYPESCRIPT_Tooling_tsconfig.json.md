Les carecterístiques de TypeScript són molt utils, per una banda permet afegir tipatge a el codi JavaScript de tota la vida. També fa el check de syntax error, abans del run time. Probeeix tooltips que et mostren perquè algun codi pot tirar un error. Per defecte hi ha molt bones feautres, tot-hi així TypeScript és flexible, algunes vegades pots no voler les [default rules](https://www.typescriptlang.org/docs/handbook/compiler-options.html) de TypeScript, i aquí és on entra el fitxer **tsconfig.json**. A part d'això et permet dir-li a TS quins fitxers mirar i com ajudar.
## Exmple de tsconfig.json i anàlisi
El fitxer **tsconfig.json** sempre es posa al root del projecte, i pots inidicar-li totes les normes que ha de seguir el compilador de TypeScript.

Aquí un exemple del fitxer **tsconfig.json**
```json
{  
"compilerOptions": {
	"target": "es2017",
	"module": "commonjs",
	"strictNullChecks": true
},
"include": ["**/*.ts"]}
```

En el JSON, hi ha diverses propietats:

- `"compilerOptions"`, és un nested object que conté les normes per el compliador de TypeScript
    - `"target"`, el valor `"es2017"` vol dir que el projecte farà servir els estandards de la versio 2017 de EcmaScript per el JavaScript
    - `"module"`, aquest projecte farà servir la sintaxis per importar i exportar moduls de `"commonjs"`.
    - `"strictNullChecks"`, les variable poden ser `null` or `undefined` només si estàn explicitament assignats aquests valors
- `"include"` determina a quins fitxers s'aplicaràn les normes. En aquest cas `["**/*.ts"]` vol dir que el compilador ha de fer el check a cada fitxer que tingui la extensió **.ts**

El fitxer **tsconfig.json** està bé tant per projectes individuals com per equips, perquè permet que tothom estigui a la mateixa pàgina pel que respecta a escriure codi.
## Ús
Algo bastant guay, es que tinguen el fitxer **tsconfig.json**, ara pots fer servir el [[./304.02.TYPESCRIPT_Tooling_TypeScript transcompiler.md|tsc]] sense cap argument a la teva terminal. El compilador detecta automaticament desde el **tsconfig.json** quins fitxes ha de fer correr.
