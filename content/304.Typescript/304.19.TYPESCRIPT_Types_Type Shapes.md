## Type Shapes
TypeScript coneix els tipus dels nostres objectes, a més també sap les formes(shapes) dels nostre objectes. 

Un Object Shape descriu, apart de moltes més coses, quines propietats i metodes té i no conté un objecte

Per exemple, els built-in types que té JavaScript  es coneixenen perfactament per TypeScript, per tant un string sabem que contindrà `.length` o `.toLowerCase()` entre altres, si si li diguem `"MY".toLowercase()` el [[./304.02.TYPESCRIPT_Tooling_TypeScript transcompiler.md|304.02.TYPESCRIPT_Tooling_TypeScript transcompiler.md]] ens donarà error, algo com `Property 'toLowercase' does not exist on type '"MY"'.`
