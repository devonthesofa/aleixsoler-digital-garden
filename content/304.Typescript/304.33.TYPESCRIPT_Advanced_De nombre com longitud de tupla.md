En TypeScript, un nombre es pot representar a nivell de tipus mitjançant la **longitud (`length`) d’una tupla**.
Aquesta tècnica permet treballar amb valors numèrics en contextos on el sistema de tipus no ofereix operacions aritmètiques directes.

La tupla es construeix recursivament fins que la seva longitud coincideix amb el nombre desitjat.

```typescript
type ReserveTupleSpace<
  N extends number,
  T extends unknown[] = []
> = T["length"] extends N
  ? T
  : ReserveTupleSpace<N, [...T, unknown]>;
```
`ReserveTupleSpace<3>` resol a una tupla de longitud `3`
## Per què pot ser útil
- Modelar nombres a nivell de tipus
	- _Permet representar valors numèrics sense variables ni codi d’execució._
- Validació en temps de compilació
	- _Errors de mida o límits es detecten abans d’executar l’aplicació._
- Base per a aritmètica de tipus
	- _És el mecanisme fonamental per implementar sumes, restes, etc._
- Cap cost en runtime
	 - _Tot passa al compilador, no afecta el rendiment de l’aplicació._

## Contextos d’ús habituals
- APIs fortament tipades
	- _Funcions que només accepten estructures amb mides concretes._
- Validació estructural
	- _Assegurar que arrays, tuples o configuracions compleixen restriccions._
- Type-level programming
	- _Programació feta exclusivament amb el sistema de tipus._
- DSLs basats en tipus
	- _Llenguatges interns on els tipus defineixen el comportament permès._
