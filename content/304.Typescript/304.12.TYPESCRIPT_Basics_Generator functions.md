Les funcions van corrent de dalt fins abaix. Les funcions generadores també ho fan, però poden ser pausades durant la execució i fer-les continuar més tard desde el mateix punt on s'han pausat. Això pot anar passant fins al final de la funció.

## Tipatge per una Generation function
Pots usar `AsyncGenerator` o `Generator`, exemple:
```typescript
type PerfReview<
	T extends AsyncGenerator<any, any, any>
> = T extends AsyncGenerator<
	infer U, any, any
> ? U : never;
```
El que està fent això és acceptar com a genèric un `AsyncGenerator`, Assegurem que així ho sigui, si no ho és retornem un tipus invalid, altrament retornem el tipus del valor **yielded**

> Els tipus dels genèrics `AsyncGenerator<never, void, unknown> ` són:
 - El primer genèric es tipo de los valores que genera (yield).
> - El segon és el tipo del valor que devuelve (return).
 - El tercer tipo del valor que acepta como entrada (next).

## Crear una Generation function
Per crear una Generator function fem servir la comanda `*`.  Exemple

```typescript
function normalFunction() {
  console.log("This is a normal function");
}
function* generatorFunction() {
  console.log("This is a generator function");
}

normalFunction(); // "This is a normal function"
generatorFunction();
```

Quan s'executa la funció generator no pintarà en pantalla el log. Aquesta funció retorna un tipus `Generator<never, void, unknown>`. **Atenció, si la funció es asincrona el tipus retornat és `AsyncGenerator<never, void, unknown>`**  Per fer correr una funció generadora s'ha de fer així:
```typescript
function* generatorFunction() {
  console.log("This is a generator function");
}

const a = generatorFunction();
a.next();
```

el retorn de `a.next()` és del tipus `IteratorResult`, aleshores si volguéssim accedir al resultat d'aquesta hauriem de fer algo com:
```typescript
const b = a.next();
console.log(b); // {"value": 3, "done": true}
console.log(b.value); // 3
```

La interfície de `Generator` extend el tipus `Iterator`, això ens permet cridar el `next`, a més té la propietat `[Symbol.iterator]` que el fa iterable. Per més informació sobre els iterables [[./304.14.TYPESCRIPT_Basics_Iterables i iteradors|304.14.TYPESCRIPT_Basics_Iterables i iteradors]]

La cosa guay dels generadors és que la execució es pausa usant el `yield`, quan es crida el `next` el generador executa codi síncron fins que ens troba amb el `yield`, que en aquest punt es pausa fins que es torna a cridar el `next` un altre vegada. Exemple:
```typescript
function* iterator() {
  yield 1
  yield 2
  yield 3
}
for(let x of iterator()) {
  console.log(x)
}
```

Això ens permet retornar multiples vegades desde la funció. A més, no es crea un array a memòria, això permet crear seqüències infinites molt més eficientment, per tant, algo com això seria possible:
```typescript
function* evenNumbers() {
  let n = 0;
  while(true) {
    yield n += 2;
  }
}
```

## Com fer recursivitat:
Com que `yield` és una expressió, es pot usar `yield*` per delegar a un altre objecte iteradors, exemple:
```typescript
function* readFilesRecursive(dir: string): Generator<string> {
  const files = fs.readdirSync(dir, { withFileTypes: true });

  for (const file of files) {
    if (file.isDirectory()) {
      yield* readFilesRecursive(path.join(dir, file.name));
    } else {
      yield path.join(dir, file.name);
    }
  }
}
```
