## Què és

És una tècnica avançada del sistema de tipus de TypeScript que **permet determinar si un tipus és un `union` o no**.
Això és útil quan estem construint **tipus genèrics reutilitzables** i volem comportaments diferents segons si el tipus és simple o compost.

TypeScript **no ofereix una utilitat integrada** per detectar unions, així que s’ha de fer amb `conditional types`.
## Problema
TypeScript tracta aquests dos casos de manera molt diferent:

```ts
string
string | number
```
Però **no hi ha cap flag directe** per saber si un tipus és un `union`.
## Idea clau
Un `union` es pot detectar perquè:

> Quan forces distribució, **cada membre s’avalua per separat**.

Si compares el tipus distribuït amb ell mateix “embolcallat”, pots detectar la diferència.
## Implementació
```typescript
type IsUnion<T, U = T> =
  T extends any
    ? [U] extends [T]
      ? false
      : true
    : never;
```
## Exemples
```typescript
type A = IsUnion<string>;          // false
type B = IsUnion<string | number>; // true
type C = IsUnion<never>;           // false
```
## Per què funciona
Quan `T` és un `union`, el `T extends any` **distribueix**:
```ts
(string extends any ? ... : ...) |
(number extends any ? ... : ...)
```
Però `U` conserva el tipus original (`string | number`).
Quan comparem `[U] extends [T]`, només falla en el cas de `union`.

# Nota 2 — **Bloquejar la distribució en Conditional Types**

## Què és

És una tècnica que **impedeix que un `conditional type` es distribueixi automàticament sobre un `union`**.

Per defecte, TypeScript **distribueix sempre que el tipus de l’esquerra sigui “nu”**.
Bloquejar la distribució et permet **tractar el `union` com un tot**. s'esplica a [[304.36.TYPESCRIPT_Advanced_Detecció de Union Types|aquí]] i  [[./304.35.TYPESCRIPT_Advanced_Forçar distribució en Conditional Types|aquí]] en detall.
## Comportament per defecte
```typescript
type ToArray<T> = T extends any ? T[] : never;

type A = ToArray<string | number>;
// string[] | number[]
```
Això és distribució automàtica.
## Bloquejar la distribució
La tècnica consisteix a **embolcallar el tipus** (normalment en una tuple):

```typescript
type ToArray<T> = [T] extends [any] ? T[] : never;

type B = ToArray<string | number>;
// (string | number)[]
```
## Exemple pràctic
Suposem que volem comprovar si un tipus és assignable, **sense distribuir**:
```typescript
type IsAssignable<T, U> =
  [T] extends [U] ? true : false;
```

```typescript
type A = IsAssignable<string | number, string>; // false
type B = IsAssignable<string, string | number>; // true
```

Sense el bloqueig, el primer cas donaria resultats incorrectes.

## Regla mental

> **Si el tipus està nu → es distribueix**
> **Si el tipus està embolcallat → no es distribueix**

Embolcalls habituals:
* `[T]`
* `{ t: T }`
* `() => T`
