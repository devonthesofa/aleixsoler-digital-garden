## Què és

És una tècnica pròpia del **sistema de tipus de TypeScript** que **consisteix a fer que un `conditional type` s’apliqui individualment a cada membre d’un tipus [[./304.18.TYPESCRIPT_Types_Union types|union]]**, en lloc de tractar el `union` com un tot.

Això s’aconsegueix posant el tipus `union` **naked** a l’esquerra de l’`extends`.

Aquesta tècnica és especialment útil quan es treballa amb **recursivitat de tipus**, **tuples**, o **transformacions avançades** on el comportament per defecte de TypeScript talla massa aviat.
## Exemple
Suposem que volem generar un `tuple` amb un tipus repetit `N` vegades:

```typescript
type Repeat<
  T,
  Times extends number,
  Acc extends T[] = []
> = Acc['length'] extends Times
  ? Acc
  : Repeat<T, Times, [...Acc, T]>;
```

Si ho fem servir així:

```typescript
type A = Repeat<'toy', 3>;
```

Resultat:

```ts
['toy', 'toy', 'toy']
```

Tot correcte.
## El problema amb unions
Ara provem amb un `union`:

```typescript
type B = Repeat<'toy', 3 | 4>;
```
Resultat inesperat:
```ts
['toy', 'toy', 'toy']
```
Per què?
Perquè quan `Acc['length']` arriba a `3`:
```ts
3 extends (3 | 4) // true
```
TypeScript **atura la recursió** i **no explora el 4**.
## Forçar la distribució
Per fer que TypeScript processi **cada valor del `union` per separat**, fem servir un `conditional type` distributiu:
```typescript
type BoxToys<T, Times extends number> =
  Times extends Times  <--- màgia
    ? Repeat<T, Times>
    : never;
```
Aquesta expressió fa que:
```ts
Times = 3 | 4
```
es transformi internament en:
```ts
Repeat<T, 3> | Repeat<T, 4>
```
## Resultat
```typescript
type C = BoxToys<'toy', 3 | 4>;
```
Resultat final:
```ts
['toy', 'toy', 'toy'] |
['toy', 'toy', 'toy', 'toy']
```
Exactament el comportament esperat.
## Per què funciona `Times extends Times`
Tot i que sembla redundant, **no és una comparació lògica real**.

És un mecanisme del sistema de tipus que diu:

> “Si `Times` és un `union`, aplica el conditional type a cada membre individualment”.

Això només passa quan:

* El tipus està **nu(naked)** a l’esquerra de l’`extends`
* No està embolicat en tuples, objectes o altres tipus
## Exemple de distribució vs no distribució

```typescript
type Distribute<T> = T extends any ? T[] : never;
type NoDistribute<T> = [T] extends [any] ? T[] : never;

type A = Distribute<string | number>;
// string[] | number[]

type B = NoDistribute<string | number>;
// (string | number)[]
```
