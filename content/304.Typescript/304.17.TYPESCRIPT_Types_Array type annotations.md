Per posar el type annotation a un array es bastant fàcil, s'ha de posar `[]` al final del tipus de l'element

Exemple:
```typescript
let names: string[] = ['Danny', 'Samantha'];
```

Una alternativa és fer servir la sintaxis `Array<T>` on `T`, és el tipus esperat
```typescript
let names: Array<string> = ['Danny', 'Samantha'];
```

Amb això tindràs controlat les variables tipus array:
```typescript
let names1: string[] = [1,2,3]; // Type Error!
let names2: string[] = ['Damien'];  
names2.push(666) // Type Error!
```

D'aquesta manera ja no hauràs de crear les tipiques funcions que controlen el tipus abans de fer el push, o en la propia assignació usant indexs rotllo `names1` dificultaria bastant el control, per tant tens coberts aquests bugs, els tipus de les variables sempre seran del tipus esperat.

## Multi-dimensional Arrays
Tant fàcil com això
```typescript
let arr: string[][] = [['str1', 'str2'], ['more', 'strings']];

let numbersMulti: number[][][] = [ [[1],[2,3]], [[7]] ];
```
## Tuples
En javaScript podem definir arrays amb diferents tipus, en TypeScript també ho podem indicar i limitar, per tant són tuples.

Quan un array especifica els tipus dels elements intern, li diem _tuple_
```typescript
let ourTuple: [string, number, string, boolean] = ['Is', 7 , 'our favorite number?' , false];
```
Les tuples especifiquen la longitud de l'array i els tipus d'aquest, si no concorda amb el tipus donarà error:
```typescript
let numbersTuple: [number, number, number] = [1,2,3,4]; // Type Error! numbersTuple should only have three elements.  
let mixedTuple: [number, string, boolean] = ['hi', 3, true] // Type Error! The first elements should be a number, the second a string, and the third a boolean.
```
En JavaScript i TypeScript podem accedir i modificar els elements usant `[index]`, independement que sigui tipus array o tuple. Però tot-hi això, no podem assignar una tuples de string amb un array de string els tipus són diferents:
```typescript
let tup: [string, string] = ['hi', 'bye'];  
let arr: string[] = ['there','there'];  
tup = ['there', 'there']; // No Errors.  
tup = arr; // Type Error! An array cannot be assigned to a tuple.
```
## Array Type Inference
TypeScript pot fer [[./304.21.TYPESCRIPT_Types_Type Inferences|304.21.TYPESCRIPT_Types_Type Inferences]]:
```typescript
let examAnswers= [true, false, false];
```
I et preguntaràs quin tipus serà examAnswers? una tupla o un array?? Dóncs bé, és un array de booleans, d'aquesta manera podrem afegir més elements sense que peti, example:
```typescript
examAnswers[3] = true; // No type error.
```
Quan fem servir el metode `concat` funciona de la mateixa manera
```typescript
let tup: [number, number, number] = [1,2,3];  
let concatResult = tup.concat([4,5,6]); // concatResult has the value [1,2,3,4,5,6].
```
## Rest Parameters
Assigning types to [rest parameters](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/rest_parameters) is similar to assigning types to [arrays](https://www.codecademy.com/resources/docs/typescript/arrays). Here’s a rest parameter example without types:

```typescript
function smush(firstString, ...otherStrings){
	let output = firstString;  
	for(let i = 0; i < otherStrings.length; i++){    
		output = output.concat(otherStrings[i]);  
	}  
	return output;
}
```
Però aquí hi ha un tema, el tipus `otherString` és `any[]` per tant no és type safe, pots posar el tipus de la seguent manera:

```typescript
function smush(firstString, ...otherStrings: string[]){  
  /*rest of function*/  
}
```

En l'example si crides la funció `smush(1,2,3)` donarà error de tipatge perquè `[2,3]` no es un array de string

## Spread Syntax
Les [tuples](https://www.codecademy.com/resources/docs/typescript/tuples) són la parella perfecte per fer [spread syntax](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax). Sobretot quan tenim funcions amb molts arguments com:
```typescript
function gpsNavigate(
	startLatitudeDegrees:number, 
	startLatitudeMinutes:number, 
	startNorthOrSouth:string, 
	startLongitudeDegrees: number, 
	startLongitudeMinutes: number, 
	startEastOrWest:string, 
	endLatitudeDegrees:number, 
	endLatitudeMinutes:number , 
	endNorthOrSouth:string, 
	endLongitudeDegrees: number, 
	endLongitudeMinutes: number,  
	endEastOrWest:string
) {  
  /* navigation subroutine here */  
}
```
En comptes de cridar:
```typescript
gpsNavigate(40, 43.2, 'N', 73, 59.8, 'W', 25, 0, 'N', 71, 0, 'W')
```
Podriem fer:
```typescript
let codecademyCoordinates: [number, number, string, number, number, string] = [40, 43.2, 'N', 73, 59.8, 'W'];  
let bermudaTCoordinates: [number, number, string, number, number, string] = [25, 0 , 'N' , 71, 0, 'W'];
```
Fent que siguin tuples garantitzem els tipus dels elements per el funcion parameters
```typescript
gpsNavigate(...codecademyCoordinates, ...bermudaTCoordinates);  
// And by the way, this makes the return trip really convenient to compute too:  
gpsNavigate(...bermudaTCoordinates, ...codecademyCoordinates);  
// If there is a return trip . . .
```
