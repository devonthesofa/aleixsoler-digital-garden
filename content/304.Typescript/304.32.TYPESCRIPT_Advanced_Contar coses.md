## Recursive Counting with Template Literals
```typescript
type Increment<N extends number, T extends unknown[] = []> =
  T['length'] extends N ? 
	  [...T, unknown]['length'] 
	  : 
	  Increment<N, [...T, unknown]>;

// Example usage:
type One = Increment<0>; // Resolves to 1
type Five = Increment<4>; // Resolves to 5
```
## Counting Using Variadic Tuple Types
```typescript
type Add<T extends unknown[], U extends unknown[]> = [...T, ...U];
type Subtract<T extends unknown[], U extends unknown[]> =
  T extends [...U, ...infer R] ? R : never;

type Length<T extends unknown[]> = T['length'];

// Example:
type Two = Add<[unknown], [unknown]>; // [unknown, unknown]
type One = Subtract<[unknown, unknown], [unknown]>; // [unknown]
type CountTwo = Length<Two>; // Resolves to 2
```
## A Practical Use Case
```typescript
type Repeat<T, N extends number, R extends unknown[] = []> =
  R['length'] extends N ? R : Repeat<T, N, [...R, T]>;

// Example usage:
type ThreeStrings = Repeat<string, 3>; // [string, string, string]

```

## Limitations
- These methods are purely compile-time constructs.
- There are practical limits to recursion depth in TypeScript (default is 1000).
- Such types can't directly interact with runtime data but can guide how your functions handle static values.
