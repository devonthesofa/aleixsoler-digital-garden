Si vols que  un tipus X no es pugui igualar a un altre de diferent, per exemple:

```typescript
declare let demand1: Demand<unknown>;
declare let demand2: Demand<string>;
declare let demand3: Demand<'Immediate 4% Pay Increase'>;
declare let demand4: Demand<'3 Days Paid Time Off Per Year'>;

type t1 = Expect<Equal<typeof demand1, { demand: unknown }>>
demand1 = demand1; // ✅
// @ts-expect-error
demand1 = demand2; 
// @ts-expect-error
demand1 = demand3;
// @ts-expect-error
demand1 = demand4;
```

Ho pots aconseguir de la següent manera:
```typescript
type Demand<T> = {
	demand: T extends T? T : ((a: T) => never);
}
```

### Fer-lo invariant
Un enfocament millor és evitar qualsevol distribució del tipus mitjançant l'encapsulació. Aquí en tens una alternativa:

```typescript
type Invariant<T> = {
  _type: T;
};
```
Amb aquest tipus, qualsevol intent d'utilitzar un tipus no exacte (A | B) fallarà, perquè no es pot distribuir dins d'una estructura encapsulada. Per exemple:

```typescript
type A = Invariant<string | number>; 
// Això no distribueix "string" i "number", el tipus es manté intacte.
```
Aquest enfocament força l'invariància encapsulant el tipus i evitant l'ús del comportament per defecte de distribució.
