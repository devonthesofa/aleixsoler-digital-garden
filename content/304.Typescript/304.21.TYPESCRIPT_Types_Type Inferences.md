## TypeScript Inferences
Javascript permet assignar `any` valor a una variable. Això és molt flexible.
Quan en Typescript inicialitzem una variable, el tipus és inferit, això vol dir que la variable tindrà el tipus del valor assignat, i aquesta variable **no es por reassignar a un valor d'un tipus diferent**. Typescript espera que el tipus de la variable faci match el mateix tipus assignat inicialment a la declaració.

Typescript reconeix:
- boolean
- number
- null
- string
- undefined

Si intentem reasingar la variable a un tipus diferent, Typescript en donarà error:
```typescript 
let order = 'first';  
  
order = 1;
```
Error esperat: `Type 'number' is not assignable to type 'string'`
