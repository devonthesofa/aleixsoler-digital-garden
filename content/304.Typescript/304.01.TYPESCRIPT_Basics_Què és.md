## Com es fa servir typescript
1. Escrivim codi TypeScript a fitxer amb la extensiḉo `.ts`
2. Tot seguit es fa correr el codi amb el [[./304.02.TYPESCRIPT_Tooling_TypeScript transcompiler.md|TypeScript Transcompiler]], aquest verificarà que el codi segueix els estandards de TypeScript, i si no ho fà donarà errors.
3. Si el codi TypeScript es pot convertir a JavaScript, el transiplador generarà un versió JavaScript en un fitxer `.js`

El TypeScript és un **superset** del codi JavaScript, per tant té les mateixes característiques que el javascript i les extén.
