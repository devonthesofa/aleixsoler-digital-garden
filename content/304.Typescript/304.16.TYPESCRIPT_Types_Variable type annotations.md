> Es pot posar type annotation a variables, funcions i classes.

A vegades volem crear una variable sense declarar-la, això com hem vist a [[./304.24.TYPESCRIPT_Types_any|304.24.TYPESCRIPT_Types_any]] farà que sigui tipus `any`, el que volem assegurar és que no sigui `any` d'aquesta manera evitarem problemes.

Li podem indicar a TypeScript quin tipus és una variable fent servir el ***type annotation (també conegut com type declarations)*** afegint al costat del nom de la variable `:` més el seu tipus.

Exemple:
```typescript
let mustBeAString : string;  
mustBeAString = 'Catdog';  
  
mustBeAString = 1337;  
// Error: Type 'number' is not assignable to type 'string'
```
