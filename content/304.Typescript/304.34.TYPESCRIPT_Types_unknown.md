## Què és `unknown`
`unknown` és el **top type segur** de TypeScript.

Representa un valor que **pot ser qualsevol cosa**, però que **no és usable directament**.  
A diferència de `any`, `unknown` **no desactiva el type checker**.

> `unknown` existeix per obligar-te a demostrar el tipus abans d’usar un valor.

## `unknown` vs `any`
Tot i que tots dos poden representar “qualsevol valor”, el seu comportament és molt diferent:

- **any**
	- Permet qualsevol operació
	- Desactiva les comprovacions de tipus
	- Pot amagar errors a runtime
- **unknown**
	- No permet accedir a propietats ni cridar mètodes
	- Obliga a validar o acotar el tipus
	- Manté la seguretat del sistema de tipus

> Regla pràctica: si no controles l’origen del valor, prefereix `unknown` abans que `any`.
## Què *no* pots fer amb `unknown`
Un valor de tipus `unknown` **no es pot usar directament**:

- No pots accedir a propietats
- No pots cridar mètodes
- No el pots assignar a un tipus més concret sense comprovacions

Això és intencionat: `unknown` **protegeix el codi de suposicions incorrectes**.
## Com es “desbloqueja” un `unknown`
`unknown` et força a ser responsable: **no pots usar el valor fins que no el validis o el tipis**.

Maneres habituals de fer-ho:
- Validació amb `typeof`
- Validació amb `instanceof`
- Type guards personalitzats
- Conversió explícita amb `as` *(només si tens garanties reals)*
## Exemple d’ús
```ts
declare let demand1: Demand<unknown>;

// Simulem una font externa
demand1 = {
  request: "Necesito un objeto de tipo boolean",
  value: true,
} as Demand<unknown>;

if (typeof demand1.value === "boolean") {
  console.log("És un boolean:", demand1.value ? "Sí" : "No");
}
````
Forçar el tipus només és segur quan **tens control total sobre l’origen del valor**:
```ts
const safeDemand = demand1 as Demand<boolean>;
```
## Quan té sentit usar `unknown`

`unknown` és especialment útil quan el valor:

* Prové d’una font externa (APIs, JSON, input d’usuari)
* Ve d’una variable global declarada amb `declare`
* Prové d’una llibreria sense tipatge
* És el resultat de dades deserialitzades

En aquests casos, `unknown` evita assumir propietats que podrien no existir a runtime.

> La part important és que el codi **no pot assumir** que un valor `unknown` és usable fins que ho comproves explícitament.
