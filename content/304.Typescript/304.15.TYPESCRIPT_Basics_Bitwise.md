## Definició de tipus amb bitwise
Els **flags** són una aplicació clàssica de bitwise. Podem definir tipus que representen combinacions d'opcions.
```typescript
enum Permissions {
    Read = 1 << 0,    // 0001 -> 1
    Write = 1 << 1,   // 0010 -> 2
    Execute = 1 << 2, // 0100 -> 4
}

type UserPermissions = Permissions;

// Exemple d'ús:
const userPerms: UserPermissions = Permissions.Read | Permissions.Write;

// Comprovació
const canWrite = (userPerms & Permissions.Write) !== 0; // true

```
## Operadors bitwise principals
### AND (&): 
Comparació bit a bit, retorna 1 només si ambdós bits són 1.

```typescript
const result = 5 & 3; // 0101 & 0011 -> 0001 (1)
```
### OR (|): 
Comparació bit a bit, retorna 1 si qualsevol dels bits és 1.

```typescript
const result = 5 | 3; // 0101 | 0011 -> 0111 (7)
```
### XOR (^): 
Retorna 1 si els bits són diferents.

```typescript
const result = 5 ^ 3; // 0101 ^ 0011 -> 0110 (6)
```
### NOT (~): 
Inverteix tots els bits (1 → 0 i 0 → 1).
```typescript
const result = ~5; // ~0101 -> 1010 (-6, en complement a dos)
```
### Shift esquerre (<<): 
Desplaça bits cap a l'esquerra, afegint zeros.

```typescript
const result = 5 << 1; // 0101 << 1 -> 1010 (10)
```
### Shift dret amb signe (>>): 
Desplaça bits cap a la dreta, mantenint el bit de signe.
```typescript
const result = 5 >> 1; // 0101 >> 1 -> 0010 (2)
```
### Shift dret sense signe (>>>): 
Igual que el dret, però omple amb zeros.

```typescript
const result = -5 >>> 1; // 111...11011 >>> 1 -> 0111...11101
```

## Casos d'ús útils
**Gestió de permisos i flags**
Es poden utilitzar valors bitwise per representar múltiples opcions en un sol número.
```typescript
const hasPermission = (flags: number, permission: number) => {
	return (flags & permission) !== 0;
}

const userFlags = Permissions.Read | Permissions.Execute; // 0101
console.log(hasPermission(userFlags, Permissions.Write)); // false
```
## Codificació compacta de dades
Es poden empaquetar diverses opcions o dades en un sol enter.
```typescript
const pack = (a: number, b: number) => (a << 8) | b;
const unpack = (value: number) => [value >> 8, value & 0xff];

const packed = pack(10, 20); // 0x0A14
const [a, b] = unpack(packed); // [10, 20]
```

## Gestió de colors o dades en gràfics
Es poden combinar components RGB o altres dades binàries.
```typescript
const combineRGB = (r: number, g: number, b: number) => (r << 16) | (g << 8) | b;
const extractRGB = (color: number) => ({
    r: (color >> 16) & 0xff,
    g: (color >> 8) & 0xff,
    b: color & 0xff,
});

const color = combineRGB(255, 128, 64);
console.log(extractRGB(color)); // { r: 255, g: 128, b: 64 }
```

## Consideracions
Els números es representen internament com a enters de 32 bits amb signe.
Les operacions bitwise poden ser menys intuïtives amb números negatius pel complement a dos.
Poden ajudar a optimitzar certs casos, però el codi pot ser menys llegible. Mantingues-ho clar amb comentaris o tipus.
