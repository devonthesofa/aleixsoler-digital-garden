En JavaScript quan definim una funció, aquest no li importa el que se li passa quan la cridem:
```javascript
function printLengthOfText(text) {  
  console.log(text.length);  
}  
  
printLengthOfText(3); // Prints: undefined
```
Els desenvolupadors han trobat error-handling solutions per evitar aquest effectes no desitgables:
```javascript
function printLengthOfText(text) {  
  if (typeof text !== 'string') {  
    throw new Error('Argument is not a string!');  
  }  
  
  console.log(text.length);  
}  
  
printLengthOfText(3); // Error: Argument is not a string!
```
Ara veurem com TypeScript gestiona aquest problema
## Parameter type annotations
Els paràmetres d'una funció poden tenir el seu type annotation de fet funciona igual que amb: [[./304.16.TYPESCRIPT_Types_Variable type annotations|304.16.TYPESCRIPT_Types_Variable type annotations]], dos punts al costat del nom:
```typescript
function greet(name: string) {  
  console.log(`Hello, ${name}!`);  
}  
  
greet('Katz'); // Prints: Hello, Katz    
  
greet(1337); // Error: argument '1337' is not assignable to parameter of type 'string'
```

**Si no li indiques un tipus,  per defecte el tipus serà ***Any***

## Optional Parameters
Per indicar que volem els parametres intencionadament opcionals, afegim el `?` despres del seu nom. Això li diu a TypeScript que el parametres es permes de ser `undefined` per tant si volem no l'hem de passar:
```typescript
function greet(name?: string) {  
  console.log(`Hello, ${name|| 'Anonymous'}!`);  
}  
  
greet(); // Prints: Hello, Anonymous!
```

## Default Parameters
Si assignem un valor per defecte, TypeScript farà [[./304.21.TYPESCRIPT_Types_Type Inferences|304.21.TYPESCRIPT_Types_Type Inferences]] el mateix tipus de la variable per defecte.
```typescript
function greet(name = 'Anonymous') {  
  console.log(`Hello, ${name}!`);  
}
```
Per tant en aquesta funció, el tipus de name pot ser `string` o `undefined`. Posar un default value implica que el tipus del paràmetre és opcional.
## Inferring Return Types
TypeScript també fà [[./304.21.TYPESCRIPT_Types_Type Inferences|304.21.TYPESCRIPT_Types_Type Inferences]] dels valors retornats de una funció, ho fa mirant els tipus declarats dels valors retornats en una funció.

## Explicit Return Types
Si es vol ser encara més explicit sobre els retorns d'una funció es pot posar el type annotation despres de tancar els parentesis:
```typescript
function createGreeting(name?: string): string {  
  if (name) {  
    return `Hello, ${name}!`;  
  }  
  
  return undefined;  
  // Typescript Error: Type 'undefined' is not assignable to type 'string'.  
};
```

```typescript
const createArrowGreeting = (name?: string): string => {  
  if (name) {  
    return `Hello, ${name}!`;  
  }  
  
  return undefined;  
  // Typescript Error: Type 'undefined' is not assignable to type 'string'.  
};
```

```typescript
function makeFruitSalad(fruit1:string, fruit2:string):void{
	let salad=fruit1+fruit2+fruit2+fruit1+fruit2+fruit1+fruit1;
	console.log(salad);

```
