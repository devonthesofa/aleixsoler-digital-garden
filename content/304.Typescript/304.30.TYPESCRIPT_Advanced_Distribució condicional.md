## Distribució condicional en unions
Aquesta estructura té sentit per crear tipus que es comporten d'una manera específica amb unions de tipus, però no per crear un tipus [[./304.28.TYPESCRIPT_Advanced_Covariant, contravariant, bivariant i invariant|invariant]]. Això és el que passa exactament amb aquest tipus:

**`T extends T`**
- Aquesta condició sempre és certa per a qualsevol tipus `T`.
- La seva utilitat rau en com es comporta amb unions: quan `T` és una unió (`A | B`), TypeScript aplica la condició individualment a cada membre de la unió. Això és el que es coneix com **distribució condicional**. Per exemple:
  ```typescript 
    type Result = Demand<string | number>;
	```
    Aquí, `T` es distribueix a `string` i `number`, generant una combinació que es processa independentment per a cada membre.

### Exemple
```typescript
type Demand<T> = {
  demand: T extends T ? T : ((a: T) => never);
};
```
És una tècnica avançada de tipus que explota com TypeScript distribueix unions per convertir una unió en una estructura més granular. No és un tipus que s'utilitzi sovint en casos generals, però pot ser útil quan necessites manipular unions de tipus en projectes complexos o biblioteques genèriques.

Es pot utilitzar en situacions on necessites treballar amb unions de tipus, però transformant-los en alguna altra estructura més manejable. Això pot ser útil, per exemple, per generar tipus d'objectes basats en cada membre d'una unió.

- **Quan `T` no és una unió**
Si `T` és un tipus simple com `string`, el resultat serà simplement:
```typescript
	{ demand: string }
```
- **El resultat de la distribució**
 Si `T` és una unió (`A | B`), el tipus resultat serà una unió d'objectes individuals, cadascun corresponent a un membre de la unió:
```typescript
Demand<string | number>  
// Es converteix en:  { demand: string } | { demand: number }
```
