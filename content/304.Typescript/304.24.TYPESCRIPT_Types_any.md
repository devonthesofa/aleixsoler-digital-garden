Les variables de tipus `any` poden ser assignades a qualsevol valor i Typescript no es queixarà.

Quan creas una variable sense iniciar el valor el TypeScript ho intentarà [[./304.21.TYPESCRIPT_Types_Type Inferences|inferenciar]] i serà type `any`

```typescript
let onOrOff;
onOrOff = 1;
onOrOff = false;
```

El codi de sobre no peta, ja que onOrOff és tipus `any` i es pot reassignar sense problemes.
