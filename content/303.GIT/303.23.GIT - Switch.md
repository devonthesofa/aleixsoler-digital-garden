# Git Switch

**Git Switch** és un comandament especialitzat exclusivament en **canviar de branca**. 

Abans de la seva [[./303.01.GIT - Introducció i Arquitectura|introducció]], s'utilitzava `[[303.22.GIT - Checkout|git checkout]]` tant per canviar de branca com per restaurar fitxers, la qual cosa generava confusió. `git switch` neteja aquesta experiència centrant-se només en el moviment entre branques.

## Comandes Essencials
### 1. Canviar a una branca existent
És la forma més ràpida de moure't entre el teu historial:
```bash
git switch nom-de-la-branca
```
### 2. Crear una branca nova i saltar-hi directament
En lloc de fer dos passos (crear i canviar), ho fas en un:
```bash
git switch -c nova-branca
```
*El flag `-c` significa "create".*
### 3. Tornar a la branca anterior
Ideal si estàs saltant ràpidament entre dues branques:
```bash
git switch -
```
### 4. Crear una branca des d'un punt específic (un [[./303.10.GIT - El Commit i Conventional Commits|commit]] o tag)
```bash
git switch -c nova-branca v1.2.0
```

## Git Switch vs. Git Checkout

| Acció                   | Git Switch (Nou)         | [[303.12.GIT_checkout\|Git Checkout]] (Antic) |
| :---------------------- | :----------------------- | :-------------------------------------------- |
| **Canviar de branca**   | `git switch <branca>`    | `git checkout <branca>`                       |
| **Crear i canviar**     | `git switch -c <branca>` | `git checkout -b <branca>`                    |
| **Tornar a l'anterior** | `git switch -`           | `git checkout -`                              |
| **Restaurar fitxers**   | (No pot)                 | `git checkout -- fitxer.txt`                  |

> [!NOTE]
> Per a la restauració de fitxers, Git va introduir un altre comandament germà: [[GIT_restore|git restore]]. Així, el vell `checkout` queda dividit en `switch` (per a branques) i `[[303.63.GIT - Restore|restore]]` (per a fitxers).

## Avantatges i Seguretat

1.  **Menys errors:** Com que no pot modificar fitxers, no corres el risc de sobreescriure canvis locals per accident mentre intentes canviar de branca.
2.  **Més intuïtiu:** El nom del comandament (`switch`) descriu exactament què estàs fent.
3.  **Comprovacions de seguretat:** Si tens canvis pendents que entrarien en conflicte amb la branca a la qual vols anar, `git switch` t'avisarà i aturarà l'operació (a menys que facis un `discard` o un `[[303.64.GIT - Stash|stash]]`).
