## `git reflog`

> [!NOTE] Important — `git reflog`
> `git reflog` mostra el registre local de moviments de referències: [[./303.10.GIT - El Commit i Conventional Commits|commits]] on has estat, canvis de [[./303.20.GIT - Conceptes Bàsics de Branca|branca]], `[[303.26.GIT - Rebase|rebase]]`, `[[303.60.GIT - Reset|reset]]`, `commit --[[303.62.GIT - Amend|amend]]`, etc. És la via principal per **recuperar commits "perduts"** després de reescriure historial.
### Comandes essencials
**Veure el reflog de `HEAD` (el més habitual):**
```bash
git reflog
```
**Versió més explícita (equivalent habitual):**
```bash
git reflog show HEAD
```
**Veure el reflog d’una branca concreta:**
```bash
git reflog show <branca>
```
**Veure el reflog amb format de [[./303.30.GIT - Visualització amb Log|log]] (molt útil per filtrar):**
```bash
git log -g
```
**Incloure totes les referències (no només `HEAD`):**
```bash
git reflog --all
```
**Mostrar dates més llegibles:**
```bash
git reflog --date=iso
```

### Com s’interpreta
Al reflog veuràs entrades tipus:
- `HEAD@{0}`, `HEAD@{1}`, `HEAD@{2}`… (posicions al temps, 0 és l’última)
- Missatges com: `rebase`, `reset`, `[[303.22.GIT - Checkout|checkout]]`, `commit`, `amend`, etc.

### Recuperar un estat anterior (ús pràctic)
1. Troba l’entrada bona:
```bash
git reflog --date=iso
```
2. Torna-hi (opció típica i directa, destructiva del working [[./303.03.GIT - Terminologia i Objectes|tree]]):
```bash
git reset --hard HEAD@{N}
```
Això usa [[303.06.GIT_reset|git reset]]: és la combinació clàssica `reflog + reset` per desfer un `rebase`, un `amend` o un `reset` mal fet.
Si aquesta branca està publicada al [[./303.40.GIT - Treball en Remot i Push|remot]], el `push` normal pot fallar. L’opció segura acostuma a ser la que tens documentada a [[303.03.GIT_push|git push]] amb `--force-with-lease`.

### Límits i advertiments importants
* El reflog és **local**: no és "historial compartit" com el repositori remot.
* Les entrades del reflog poden desaparèixer amb el temps(expiració). Per això, si has de recuperar alguna cosa, **fes-ho aviat**.
* Hi ha comandes per caducar o netejar reflogs (normalment no cal tocar-les), com:
  ```bash
  git reflog expire --expire=now --all
  ```
Òbviament aquesta acció pot fer més difícil recuperar coses. Evita-la si no tens clar què estàs fent.
