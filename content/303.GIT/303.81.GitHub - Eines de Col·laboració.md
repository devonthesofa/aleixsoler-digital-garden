# Eines de Col·laboració a GitHub

GitHub afegeix capes de comunicació sobre Git:

- **Issues:** Per rastrejar idees, bugs, tasques o feedback. Es poden assignar responsables, etiquetes i fites.
- **Discussions:** Fòrum públic per a converses que no estan directament relacionades amb el codi (preguntes, anuncis).
- **[[./303.40.GIT - Treball en Remot i Push|Pull]] Requests:** Mecanisme per revisar codi abans d'integrar-lo.
- **Labels:** Categories per organitzar Issues i PRs (ex: `bug`, `enhancement`, `help wanted`).
- **Actions:** Automatització de tasques (CI/CD). Permet executar tests o desplegar codi automàticament quan passa un esdeveniment (com un `push`).
- **Pages:** Servei d'allotjament de llocs web estàtics directament des d'un repositori.
