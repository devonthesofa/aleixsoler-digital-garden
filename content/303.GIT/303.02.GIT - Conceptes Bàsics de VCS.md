# VCS - Version Control System

Un **Version Control System (VCS)** o **Software Configuration Management (SCM)** és un programa o conjunt de programes que rastreja els canvis en una col·lecció de fitxers.

## Objectius principals
- **Recuperació:** Poder recuperar fàcilment versions anteriors de fitxers individuals o del projecte sencer.
- **Col·laboració:** Permetre que diversos membres de l'equip treballin en un projecte (fins i tot en el mateix fitxer) alhora sense afectar la feina dels altres.

## Capacitats del VCS
- Veure tots els canvis: qui els va fer i quan.
- Missatges de canvi per explicar el motiu de cada modificació.
- Crear **Branches** ([[./303.20.GIT - Conceptes Bàsics de Branca|branques]]) per treballar de forma experimental sense afectar la línia principal.
- Afegir **Tags** per marcar versions específiques (com un llançament/release).
