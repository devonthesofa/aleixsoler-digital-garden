# Git - Terminologia i Internals

Per entendre Git, cal conèixer com anomena els seus components i com guarda la informació.

- **Working Tree:** El conjunt de directoris i fitxers en els quals estàs treballant actualment.
- **Repository (Repo):** El directori (generalment `.git`) on Git guarda tota la història i metadades.
- **Hash:** Un número (SHA-1 de 160 bits) que representa el contingut d'un fitxer o objecte. Si el contingut canvia, el hash canvia.

## Els 4 tipus d'Objectes de Git
Tot a Git es guarda com un objecte amb un hash únic:
1. **Blob:** Conté el contingut d'un fitxer ordinari.
2. **Tree:** Representa un directori; conté noms, hashes i permisos dels fitxers/subdirectoris.
3. **[[./303.10.GIT - El Commit i Conventional Commits|Commit]]:** Representa una versió específica del *Working Tree* (inclou autor, data i missatge).
4. **Tag:** Un nom vinculat a un commit.
