# `git checkout` - canviar de branca o estat

> [!NOTE] Important - `git checkout`
> El comandament `git checkout` s’utilitza per **canviar el context de treball**:
> mou el `HEAD` cap a una altra [[./303.20.GIT - Conceptes Bàsics de Branca|branca]], [[./303.10.GIT - El Commit i Conventional Commits|commit]] o [[./303.72.GIT - Tags|etiqueta]], actualitzant el directori de treball perquè coincideixi amb aquell estat.

## Canviar de branca

### Canviar a una branca existent

```bash
git checkout develop
```
- Mou `HEAD` a la branca indicada.
- El directori de treball s’actualitza amb el seu contingut.

### Crear i canviar a una branca nova

```bash
git checkout -b feature/add-login
```

Equivalent a `branch`:

```bash
git branch feature/add-login
git checkout feature/add-login
```

> Forma habitual de començar una branca de treball.

## Canviar a un commit concret

```bash
git checkout <hash>
```

- Et situes en un estat [[303.22.GIT - Checkout#Detached HEAD (estat desconnectat)|detached HEAD]].
- No estàs sobre cap branca.

> [!warning] Atenció
> Qualsevol commit fet aquí **no quedarà referenciat** per cap branca si no en crees una.

## Detached HEAD (estat desconnectat)

> [!NOTE] Important
> Estar en *detached HEAD* vol dir que `HEAD` apunta directament a un commit, no a una branca.

Casos habituals:
- Revisar un estat antic del codi.
- Provar alguna cosa puntual.
- Inspeccionar un bug del passat.

Si vols conservar canvis fets aquí:

```bash
git checkout -b nova-branca
```

## Restaurar fitxers (ús històric)
`git checkout` també pot restaurar fitxers, tot i que avui dia és preferible [[./303.63.GIT - Restore|git restore]].
### Restaurar un fitxer des de l’últim commit

```bash
git checkout -- fitxer.txt
```

- Descarta canvis locals d’aquest fitxer.
- Acció destructiva.
### Restaurar un fitxer des d’un commit concret

```bash
git checkout <hash> -- fitxer.txt
```

- Porta el fitxer a l’estat d’aquell commit.
- El canvi queda al directori de treball (caldrà `commit`).
## Limitacions i advertiments
- No pots canviar de branca si tens canvis locals conflictius.
- Git et demanarà:
	- fer [[./303.10.GIT - El Commit i Conventional Commits|commit]]
	- fer [[./303.64.GIT - Stash|stash]]
	- o descartar canvis

## Evolució: `git switch` i `git restore`

> En versions modernes de Git, `checkout` s’ha dividit conceptualment:

- [[./303.23.GIT - Switch|git switch]] → canviar de branca
- [[./303.63.GIT - Restore|git restore]] → restaurar fitxers

Tot i això, `git checkout` **continua sent totalment vàlid** i molt utilitzat.
