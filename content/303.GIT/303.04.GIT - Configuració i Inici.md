# Configuració Inicial

## Identitat
Abans de fer [[./303.10.GIT - El Commit i Conventional Commits|commits]], cal definir qui ets. Aquesta configuració es desa al fitxer `.gitconfig`.
- **Global (tots els projectes):**
  - `git config --global user.name "El Teu Nom"`
  - `git config --global user.email "correu@exemple.com"`
- **Local (només un projecte):**
  - `git config user.name "Nom"`
- **Llistar configuració:** `git config --list`

## Iniciar un repositori
- Crear un repositori nou: `git init`
- Especificar la [[./303.20.GIT - Conceptes Bàsics de Branca|branca]] inicial: `git init -b main` o `git init --initial-branch=main`

## Clonar un repositori existent
Pots clonar mitjançant URL (HTTPS/[[./303.05.GIT - Setup de Claus SSH|SSH]]) o rutes locals:
- `git clone <url>`
- `git clone ../repositori-local .` (clona el repo local a la carpeta actual)
