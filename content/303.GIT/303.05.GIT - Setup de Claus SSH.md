# [[./303.04.GIT - Configuració i Inici|Configuració]] de claus SSH per a GitHub
Si reps un error de "Permission denied (publickey)" o el repositori no reconeix la teva identitat, segueix aquests passos per configurar o revisar la teva connexió segura.

---

## 1. Comprovar claus existents
Abans de crear-ne una de nova, mira si ja tens alguna identitat creada al teu directori de configuració:

```bash
ls -al ~/.ssh/id_*
```
*Si veus fitxers com `id_ed25519.pub` o `id_rsa.pub`, ja tens claus. Si no apareix res, passa al punt 2.*

---

## 2. Generar una nova clau SSH
Si no en tens cap, genera'n una utilitzant l'algorisme **ed25519** (és el més segur i modern actualment):

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```
* Prem **Enter** per desar-la a la ruta per defecte.
* Recomanació: Posa-li una **passphrase** (contrasenya) per a més seguretat.

---

## 3. Activar l'Agent SSH
Aquest pas és important perquè el teu sistema recordi la clau i no t'hagi de demanar la contrasenya constantment:

```bash
# Iniciar l'agent en segon pla
eval "$(ssh-agent -s)"

# Afegir la teva clau privada a l'agent
ssh-add ~/.ssh/id_ed25519
```

---

## 4. Afegir la clau pública a GitHub
Copia el contingut del fitxer **públic** (el que acaba en `.pub`):

```bash
cat ~/.ssh/id_ed25519.pub
```

### Passos a la web de GitHub:
1. Ves a **Settings** (clicant a la teva foto de perfil).
2. Al menú lateral, busca **SSH and GPG keys**.
3. Clica a **New SSH key**.
4. Posa un títol descriptiu (ex: "Linux Personal") i enganxa el codi al camp **Key**.
5. Clica **Add SSH key**.

---

## 5. Verificar la connexió
Comprova si GitHub et reconeix correctament:

```bash
ssh -T git@github.com
```

> [!SUCCESS] **Resultat esperat**
> Hauries de rebre un missatge com aquest:
> `Hi [el-teu-usuari]! You've successfully authenticated, but GitHub does not provide shell access.`

---

## Consell Extra: HTTPS a SSH
Si el teu repositori encara et demana usuari i contrasenya, és perquè el tens configurat per **HTTPS**. Canvia'l a **SSH** amb aquest comandament:

```bash
git [[303.40.GIT - Treball en Remot i Push|remote]] set-url origin git@github.com:usuari/nom-del-repo.git
```
