# Git: El VCS Distribuït

**Git** és un sistema de control de versions ràpid, versàtil i altament escalable. Creat per **Linus Torvalds** (el creador de Linux).

## Control de Versions Distribuït
A diferència dels sistemes centralitzats (com SVN o Perforce), Git és **distribuït**.

- **Historial local:** L'historial complet del projecte es guarda tant al client com al servidor.
- **Treball offline:** Pots editar fitxers i fer [[./303.10.GIT - El Commit i Conventional Commits|commits]] sense connexió a xarxa; et sincronitzes amb el servidor quan la connexió torna a estar disponible.
- **Redundància:** Si el servidor cau, cada desenvolupador té una còpia completa de l'historial del projecte.
