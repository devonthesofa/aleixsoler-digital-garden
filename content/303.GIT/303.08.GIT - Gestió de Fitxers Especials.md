# Fitxers Especials i Eliminació

## .gitignore
Fitxer per indicar a Git quins fitxers o carpetes NO ha de rastrejar mai (fitxers temporals, logs, claus privades, `node_modules`).
Exemple:
- `*.bak` (tots els fitxers .bak)
- `tmp/` (tota la carpeta tmp)

## .git-keep
Git no rastreja carpetes buides. Per mantenir l'estructura de carpetes al repositori, és convenció afegir un fitxer buit anomenat `.git-keep` dins de la carpeta que volem conservar.

## Deixar de rastrejar un fitxer
Si vols borrar un fitxer del repositori (i del disc) i que Git deixi de seguir-lo:
`git rm <fitxer>`
