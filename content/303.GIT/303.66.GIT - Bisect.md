## Git bisect [^1]

_Bisect_ significa partir por la mitad y es justamente lo que va a hacer este comando: ir dividiendo toda la pila de [[./303.10.GIT - El Commit i Conventional Commits|commits]] en dos partes, una parte de la pila contendrá el error y otra parte no.

1. `git bisect start`![[../Attachments/Pasted image 20250313094926.png|Pasted image 20250313094926.png]]
2.  Si ya sabemos el commit del error, podemos pasar directamente el número de commit, pero en nuestro ejemplo vamos a usar `HEAD` para que el commit que estamos viendo sea el que está en producción.
	1. `git bisect bad` ![[../Attachments/Pasted image 20250313094916.png|Pasted image 20250313094916.png]]
3. Ya hemos indicado cuál es el commit que sabemos que tiene el error, ahora nos toca indicar un commit que sabemos que funciona correctamente. Podemos ir bastante atrás (por ejemplo, una semana atrás donde no ocurría el problema) y hacemos [[./303.22.GIT - Checkout|checkout]] a ese commit.
	1. `git checkout 587d364d` # 587d364d es un commit de hace una semana
	2. `git bisect good` # indicamos que este commit sí funcionaba![[../Attachments/Pasted image 20250313094900.png|Pasted image 20250313094900.png]]
	3. También lo puedes hacer en un solo comando con `git bisect good 587d364d`.
4. Una vez hecho esto, `git bisect` cambiará el `HEAD` por un commit entre los sospechosos y nos indicará el número de pasos que deberíamos hacer para encontrar el error y el número de commits por revisar.
5. En este punto deberemos probar el código para ver si el commit que probamos contiene el error. Si contiene el error ejecutamos `git bisect bad` y, si no lo contiene, ejecutamos `git bisect good`.
	1. En cualquiera de los dos casos, `git bisect` volverá a cambiar el `HEAD` por otro commit para que volvamos a hacer la prueba y repetiremos los pasos hasta que definitivamente nos indique en qué commit se introdujo el problema.![[../Attachments/Pasted image 20250313095432.png|Pasted image 20250313095432.png]]
6. Una vez que tengamos el commit, debemos ejecutar `git bisect [[303.60.GIT - Reset|reset]]` para reestablecer el `HEAD` correcto y finalizar el proceso.
