# Git Restore
**Git Restore** és un comandament introduït a la versió 2.23 de Git per encarregar-se exclusivament de **restaurar fitxers** al seu estat original o a un estat anterior. 

Abans, s'utilitzava [[./303.22.GIT - Checkout|git checkout]] per a aquesta tasca, però ara `git restore` ofereix una sintaxi molt més clara per desfer canvis tant al teu directori de treball com a l'àrea de preparació (*[[./303.06.GIT - Estats dels Fitxers|staging area]]*).

---
## Comandes Essencials
### 1. Descartar canvis en un fitxer (Working Directory)
Si has modificat un fitxer i vols que torni a estar com en l'últim [[./303.10.GIT - El Commit i Conventional Commits|commit]] (borrar el que has escrit):
```bash
git restore nom-del-fitxer.txt
```
*Això sobreescriu els teus canvis locals amb la versió que hi ha a l'índex.*
### 2. Traure un fitxer de l'àrea de preparació (Unstage)
Si has fet `git add` per error i vols que el fitxer torni a estar "modificat" però no llest per al commit:
```bash
git restore --staged nom-del-fitxer.txt
```
*Això equival a l'antic `[[303.60.GIT - Reset|git reset]] HEAD <fitxer>`  -> [[./303.60.GIT - Reset|reset]]
### 3. Desfer canvis a tot el directori
Si vols netejar tots els canvis no guardats de la carpeta actual:
```bash
git restore .
```

---

## Opcions Avançades

### Restaurar des d'un commit específic
Pots dir-li a Git que vols que un fitxer torni a l'estat que tenia en un commit concret del passat o en una altra [[./303.20.GIT - Conceptes Bàsics de Branca|branca]]:
```bash
git restore --source=nom-branca-o-hash fitxer.js
```

### Restaurar fitxers i l'estat d'staging alhora
Si vols desfer el `git add` i també els canvis del fitxer en un sol pas:
```bash
git restore --staged --[[303.71.GIT - Worktree|worktree]] fitxer.txt
```

---

## La divisió de [[./303.22.GIT - Checkout|Checkout]]

Com hem vist en la nota de [[./303.23.GIT - Switch|git switch]], Git ha separat les funcions del vell `checkout` en dos:

| Acció | Comandament Nou | Comandament Antic |
| :--- | :--- | :--- |
| **Moure's entre branques** | `git switch` | `git checkout` |
| **Desfer canvis en fitxers** | `git restore` | `git checkout -- <fitxer>` |
| **Unstage (traure de l'add)** | `git restore --staged` | `git reset HEAD <fitxer>` |

---

## Atenció i Seguretat

> [!CAUTION] **Acció Irreversible**
> Quan fas servir `git restore` sobre el teu directori de treball (sense el flag `--staged`), els canvis que no hagin estat guardats en un commit **es perdran per sempre**. Git no té una "paperera de reciclatge" per a canvis que mai s'han enviat al repositori.
