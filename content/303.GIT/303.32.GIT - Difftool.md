# Visualització de Canvis amb `git difftool`
**Git Difftool** és la versió gràfica del comandament `git diff`. En lloc de llegir les línies de text amb colors a la terminal, obre una interfície visual (GUI) per comparar fitxers costat a costat.

---

## `difftool` vs [[./303.24.GIT - Merge i Mergetool|mergetool]]
- **`git difftool`**: S'utilitza per **mirar** les diferències (com he canviat el codi? què hi ha de nou en aquesta [[./303.20.GIT - Conceptes Bàsics de Branca|branca]]?).
- **`git mergetool`**: S'utilitza per **arreglar** [[./303.25.GIT - Resolució de Conflictes en package-lock|conflictes]] quan Git no sap quina versió triar durant un merge.

---

## Comandaments Bàsics

### 1. Veure canvis actuals (sense commitejar)
Compara el teu directori de treball amb l'últim [[./303.10.GIT - El Commit i Conventional Commits|commit]]:
```bash
git difftool
```

### 2. Comparar entre dues branques
```bash
git difftool branca-A..branca-B
```

### 3. El mode Directori (Molt recomanat)
Per defecte, Git obre l'eina fitxer per fitxer (tanca un, obre l'altre). Amb el flag `-d`, obre l'eina mostrant tota l'estructura de carpetes a l'esquerra:
```bash
git difftool -d
```

---

## [[./303.04.GIT - Configuració i Inici|Configuració]] amb Meld

Perquè Git sàpiga que vols fer servir el **Meld** (o qualsevol altra eina com VS Code):

```bash
# Configura Meld com a eina de diff
git config --global diff.tool meld

# Obre el programa directament sense demanar confirmació
git config --global difftool.prompt false
```

### Configuració avançada al `.gitconfig`
Si prefereixes editar el fitxer manualment (`git config --global --edit`):

```ini
[diff]
    tool = meld
[difftool]
    prompt = false
[difftool "meld"]
    path = /usr/bin/meld  # (O la ruta on estigui instal·lat)
```

---

## Eines Visuals Recomanades
- **Meld:** Interfície neta, ràpida i ideal per a Linux/Windows.
- **VS Code:** Pots fer-lo servir de difftool:
	`git config --global diff.tool default-difftool`
	`git config --global difftool.default-difftool.cmd "code --wait --diff $LOCAL $REMOTE"`
