# Resolució de Conflictes amb `git mergetool`

Quan els marcadors de text (```<<<<<<<, =======, >>>>>>>```) no són suficients, Git permet llançar una **GUI (Interfície Gràfica)** per resoldre [[./303.25.GIT - Resolució de Conflictes en package-lock|conflictes]] de forma visual. Això permet veure les [[./303.20.GIT - Conceptes Bàsics de Branca|branques]] costat a costat i triar els canvis amb un clic.

---

## Comandaments Bàsics

### 1. Llançar l'eina de merge
Un cop Git t'avisa que hi ha conflictes, executa:
```bash
git mergetool
```
*Git obrirà l'eina configurada per defecte (o et preguntarà quina vols fer servir).*
### 2. Llistar eines disponibles
Per saber quins programes tens instal·lats al sistema que Git sap utilitzar:
```bash
git mergetool --tool-help
```

### 3. Utilitzar una eina específica puntualment
Si vols provar una eina concreta sense canviar la [[./303.04.GIT - Configuració i Inici|configuració]] global:
```bash
git mergetool --tool=meld
```

---

## Configuració de Meld (o altres)

Per no haver d'especificar l'eina cada vegada, la pots configurar al teu `.gitconfig`:

```bash
# Configura Meld com a eina per defecte
git config --global merge.tool meld

# Evita que et pregunti cada vegada si vols obrir el programa
git config --global mergetool.prompt false
```

> [!TIP] **Neteja de fitxers `.orig`**
> Per defecte, Git crea fitxers de seguretat amb l'extensió `.orig` després del merge. Si t'aturen, pots desactivar-ho amb:
> `git config --global mergetool.keepBackup false`

---

## Entendre la visualització (Les 4 finestres)

La majoria d'eines com **Meld**, **KDiff3** o **P4Merge** solen mostrar 3 o 4 panells:

| Nom                                                  | Contingut                                                             |
| :--------------------------------------------------- | :-------------------------------------------------------------------- |
| **LOCAL**                                            | La teva branca actual (on estàs fent el merge).                       |
| **[[./303.40.GIT - Treball en Remot i Push\|REMOTE]]** | La branca que està entrant (la que vols fusionar).                    |
| **BASE**                                             | L'ancestre comú (com estava el fitxer abans dels canvis de tots dos). |
| **MERGED**                                           | El resultat final (el que s'ha d'editar i desar).                     |
