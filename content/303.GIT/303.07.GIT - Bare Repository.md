# Repositori Nu (Bare Repository)

Un **Bare Repository** és un repositori que **no té Working [[./303.03.GIT - Terminologia i Objectes|Tree]]** (no hi ha fitxers editables, només la carpeta `.git`). S'usa habitualment com a repositori central en un servidor.

## Avantatges
- Tothom pot fer [[./303.40.GIT - Treball en Remot i Push|push]] sense preocupar-se de quina [[./303.20.GIT - Conceptes Bàsics de Branca|branca]] hi ha "oberta" al servidor.
- Escala millor per a molts col·laboradors.
- Actua com a "font de la veritat".

## Creació
1. `mkdir projecte.git && cd projecte.git`
2. `git init --bare`
3. Definir branca principal: `git symbolic-ref HEAD refs/heads/main`

## Enviar codi al Bare Repo des d'un repo local
1. `git remote add origin ../projecte.git`
2. `git push -u origin main` (L'opció `-u` o `--set-upstream` configura el rastreig per defecte).
