# Resolució de conflictes al `package-lock.json`
Els conflictes al fitxer `package-lock.json` són molt habituals quan dues persones afegeixen o actualitzen dependències simultàniament. Com que és un fitxer autogenerat de milers de línies, **mai s'ha d'intentar arreglar manualment**.

## Passos per solucionar-ho
Si et trobes enmig d'un `[[303.24.GIT - Merge i Mergetool|merge]]` o `[[303.26.GIT - Rebase|rebase]]` i el `package-lock.json` té conflictes, segueix aquest flux:
### 1. Triar una base
Primer, decidim quedar-nos amb la versió del fitxer de la [[./303.20.GIT - Conceptes Bàsics de Branca|branca]] que està entrant (la que estem fusionant). Això neteja els marcadors de conflicte (`<<<<<<<`):
```bash
[[303.22.GIT - Checkout|git checkout]] --theirs package-lock.json
```
*(Si vols prioritzar la teva branca actual, pots fer servir `--ours`, però el pas següent és el que realment importa).*
### 2. Regenerar el fitxer
Ara que el fitxer no té marcadors de conflicte però potser no coincideix amb el teu `package.json`, forcem el gestor de paquets a recalcular-ho tot:
```bash
npm install
```
*Aquest comandament llegeix el `package.json` (que ja hauries d'haver resolt prèviament si tenia conflictes), instal·la el que falta i **regenera l'estructura correcta** del lockfile.*
### 3. Marcar com a resolt
Un cop el fitxer s'ha tornat a generar correctament, l'afegim al [[./303.10.GIT - El Commit i Conventional Commits|commit]]:
```bash
git add package-lock.json
```

---

## Atenció: El `package.json` primer
Aquest mètode només funciona si el fitxer **`package.json`** (el senzill) ja ha estat resolt i no té conflictes. 

1. Arregla els conflictes de `package.json` manualment (tria quines llibreries vols mantenir).
2. Fes el `git add package.json`.
3. Llavors segueix els passos del `package-lock` explicats a dalt.

---

## Per què fem servir `npm install`?
En lloc de tornar-nos bojos buscant parèntesis tancats al JSON, deixem que `npm` comprovi l'estat de la carpeta `node_modules` i el `package.json`. Ell és l'únic que sap exactament quina estructura de dependències és vàlida i segura.
