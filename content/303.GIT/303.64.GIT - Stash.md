# Git Stash
**Git Stash** és com un "calaix de sastre" o una prestatgeria temporal on pots desar els teus canvis actuals (que encara no estan llestos per ser un [[./303.10.GIT - El Commit i Conventional Commits|commit]]) per deixar el directori de treball net i poder canviar de context ràpidament.
## Flux de treball bàsic
Si estàs treballant en una funcionalitat i de cop has de canviar de [[./303.20.GIT - Conceptes Bàsics de Branca|branca]] per arreglar un bug urgent:
1. **Desa els canvis al calaix:**
   ```bash
   git stash
   ```
   *Això deixa el teu directori de treball tal com estava en l'últim commit.*
2. **Fes la feina urgent** en l'altra branca.
3. **Torna i recupera els teus canvis:**
   ```bash
   git stash pop
   ```

---

## Comandes Essencials

| Comandament | Descripció |
| :--- | :--- |
| `git stash` o `git stash [[303.40.GIT - Treball en Remot i Push|push]]` | Desa els canvis (fitxers modificats i en el *stage*). |
| `git stash list` | Llista tots els [[303.06.GIT - Estats dels Fitxers|estats]] que tens desats. |
| `git stash pop` | Aplica l'últim stash i **l'elimina** de la llista. |
| `git stash apply` | Aplica l'últim stash però el **manté** a la llista. |
| `git stash drop` | Elimina l'últim stash de la llista sense aplicar-lo. |
| `git stash clear` | Buida completament el calaix (elimina tots els stashes). |

## Trucs Avançats

### 1. Donar nom als Stashes
Si fas diversos stashes, és difícil recordar què era cada cosa. Pots afegir-hi un missatge:
```bash
git stash push -m "Refactorització del botó de login"
```

### 2. Incloure fitxers nous (untracked)
Per defecte, `git stash` només desa fitxers que ja estaven sota el control de Git. Si has creat fitxers nous, has de fer:
```bash
git stash -u   # --include-untracked
```

### 3. Recuperar un stash específic
Si en tens molts, pots triar quin aplicar usant l'índex que surt al `list`:
```bash
git stash apply stash@{2}
```

### 4. Veure què hi ha dins d'un stash
Abans d'aplicar-lo, pots mirar quins canvis conté:
```bash
git stash show -p   # El flag -p mostra el [[303.31.GIT - Comparació amb Diff|diff]] complet
```

## Gestió de [[./303.25.GIT - Resolució de Conflictes en package-lock|Conflictes]]

De vegades, quan fas un `git stash pop`, Git pot trobar conflictes si el codi de la branca ha canviat mentre tu no hi eres.
1. Git t'avisarà dels conflictes.
2. Resol els conflictes manualment com en un *[[./303.24.GIT - Merge i Mergetool|merge]]*.
3. **Atenció:** Quan hi ha conflictes, `git stash pop` **no elimina** el stash de la llista automàticament. Hauràs de fer un `git stash drop` manualment un cop estiguis segur que tot està bé.

## Git Stash vs. [[./303.71.GIT - Worktree|Git Worktree]]

| Característica | Git Stash                             | [[303.13.GIT_Worktree\|Git Worktree]]       |
| :------------- | :------------------------------------ | :------------------------------------------ |
| **Objectiu**   | Pausa temporal en la mateixa carpeta. | Multitasa en carpetes diferents.            |
| **Velocitat**  | Molt ràpid per canvis petits.         | Més lent (cal crear carpeta/dependències).  |
| **Context**    | Ideal per "netejar" la branca actual. | Ideal per comparar branques o tests llargs. |
