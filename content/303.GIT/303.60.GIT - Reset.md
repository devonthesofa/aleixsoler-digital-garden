## `git reset` - moure `HEAD` i desfer [[./303.10.GIT - El Commit i Conventional Commits|commits]]

> [!NOTE] Important — `git reset`
> El comandament `git reset` s’utilitza per **moure el punter de `HEAD` a un commit anterior**.
> Segons l’opció utilitzada, també pot modificar l’índex (*[[./303.06.GIT - Estats dels Fitxers|staging area]]*) i el directori de treball.

És una eina per:
- Eliminar commits recents.
- Desfer confirmacions.
- Reorganitzar feina local abans de tornar a fer commits.


> [!warning] Perill
> `git reset` **reescriu l’historial**. Si després fas un `git push`, pots arribar a **sobreescriure canvis al repositori remot**.

## Com afecta l’historial
- Els commits "eliminats" deixen de formar part de la [[./303.20.GIT - Conceptes Bàsics de Branca|branca]].
- Els hashes canvien.
- En branques ja publicades, un `push` normal fallarà i pot requerir un [[./303.40.GIT - Treball en Remot i Push|push]] forçat.

Per aquest motiu, **no s’ha d’utilitzar en branques compartides** a no ser que sàpigues exactament què estàs fent.

## Tipus principals de `git reset`

### `git reset --soft`

> Mou `HEAD`, però **manté els canvis a l’índex i al directori de treball**.

- Els fitxers segueixen preparats per fer `commit`.
- Ideal per modificar l’historial sense perdre feina.

```bash
git reset --soft HEAD~1
```

Ús habitual: "Vull desfer l’últim commit però tornar-lo a fer millor".

### `git reset --mixed` (opció per defecte)

> Mou `HEAD` i **treu els canvis de l’índex**, però els manté al directori de treball.

- Els fitxers queden modificats però **no** en staging.

```bash
git reset HEAD~1
```

Ús habitual: desfer un commit i revisar què vols tornar a afegir.

### `git reset --hard`

> Mou `HEAD` i **elimina tant l’índex com els canvis del directori de treball**.


> [!warning] Perill
> Acció destructiva: perds canvis no confirmats.


```bash
git reset --hard HEAD~1
```

Ús habitual: descartar completament un estat que no vols conservar.

## Exemples

### Desfer l’últim commit però conservar els fitxers
```bash
git reset HEAD~1
```
### Desfer l’últim commit i conservar-lo en staging
```bash
git reset --soft HEAD~1
```
### Desfer l’últim commit i eliminar-ne el codi
```bash
git reset --hard HEAD~1
```

Pots substituir `1` per qualsevol nombre per indicar quants commits vols eliminar.



> [!warning] Avís important sobre merges
>  **Evita `git reset` si hi ha merges implicats**, especialment en branques compartides.

- Pots reescriure commits que provenen d’altres branques.
- Pots deixar l’historial en un estat incoherent.
- És fàcil afectar feina que no és teva.

En aquests casos, acostuma a ser millor [[./303.61.GIT - Revert|revertir]] o treballar amb altres estratègies.

## Recuperació

Encara que `git reset` sembli irreversible, sovint pots recuperar estats anteriors utilitzant el registre intern de Git ([[./303.65.GIT - Reflog|reflog]]) i tornant-hi amb un altre `reset`.
