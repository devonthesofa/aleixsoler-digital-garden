# Els Estats de Git

Dins d'un repositori, un fitxer pot passar per diversos estats:

## 1. Untracked (No rastrejat)
Estat inicial. Git sap que el fitxer existeix al disc però no en fa cap seguiment.

## 2. Tracked (Rastrejat)
Git monitoritza el fitxer. Dins d'aquest estat hi ha sub-estats:
- **Unmodified:** El fitxer està al repositori i no ha canviat des de l'últim [[./303.10.GIT - El Commit i Conventional Commits|commit]].
- **Modified:** El fitxer ha canviat des de l'últim commit, però els canvis no s'han afegit a l'índex.
- **Staged ([[./303.00.GIT - Index|Index]]):** Els canvis s'han afegit a l'àrea de preparació. Estan llestos per al següent commit.
- **Committed:** Els canvis s'han desat a la base de dades del repositori.
