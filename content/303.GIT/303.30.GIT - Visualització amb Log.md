# Visualització de Logs i Gràfics
Llegir el log per defecte de Git pot ser aclaparador. Aquestes opcions et permeten veure la història del projecte de forma visual, compacta i entenedora.
## 1. El Log Simplificat (Més clar)
Si només vols veure què s'ha fet sense que cada [[./303.10.GIT - El Commit i Conventional Commits|commit]] ocupi mitja pantalla:
```bash
git log --oneline
```
*Mostra: `[7 caràcters del hash] [missatge del commit]`.*

## 2. Veure el Gràfic de [[./303.20.GIT - Conceptes Bàsics de Branca|Branques]]
Per entendre d'on venen les branques i on s'han fusionat (*merges*):
```bash
git log --graph --oneline --all
```
- **`--graph`**: Dibuixa les línies de colors a l'esquerra.
- **`--oneline`**: Manté la informació compacta.
- **`--all`**: (Opcional) Mostra totes les branques, no només la que tens activa.

---

## 3. Veure el Log en [[./303.40.GIT - Treball en Remot i Push|Remot]]
Git no mira "en directe" al servidor cada vegada que fas un log. Per veure què hi ha al remot (per exemple, a `origin`), has d'especificar la branca de seguiment:

* **Veure una branca específica del servidor:**
  ```bash
  git log origin/main
  ```
* **Comparar què tens tu que no estigui al servidor:**
  ```bash
  git log main..origin/main
  ```

---

## 4. El "Log Definitiu" (Pro Tip)
Si vols una visualització realment professional que inclogui dates i autors de forma compacta, aquest és el comandament "rei":

```bash
git log --graph --oneline --decorate --all
```

O una versió encara més polida amb colors i dates:
```bash
git log --graph --pretty=format:'%C(yellow)%h%Creset -%C(auto)%d%Creset %s %Cgreen(%cr) %C(bold blue)<%an>%Creset' --all
```

> [!TIP] **Crea un àlies!**
> No vols escriure tot això cada vegada. Pots crear un àlies anomenat `git lg`:
> `[[303.04.GIT - Configuració i Inici|git config]] --global alias.lg "log --graph --oneline --decorate --all"`
> Ara, només escrivint **`git lg`** ho tindràs tot.
