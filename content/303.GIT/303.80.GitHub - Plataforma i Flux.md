# GitHub: La plataforma de col·laboració

**GitHub** és una plataforma al núvol que utilitza Git com a tecnologia central. Facilita la col·laboració mitjançant una interfície web i eines addicionals.

## El Flux de GitHub (GitHub Flow)
1. Crear una [[./303.20.GIT - Conceptes Bàsics de Branca|branca]] per a un canvi/feature.
2. Realitzar els canvis i fer [[./303.10.GIT - El Commit i Conventional Commits|commits]].
3. Obrir un **[[./303.40.GIT - Treball en Remot i Push|Pull]] Request ([[./303.41.GIT - Traçabilitat de Commits i Pull Requests|PR]])** per demanar feedback.
4. Discutir i implementar millores basades en el feedback.
5. Fusionar ([[./303.24.GIT - Merge i Mergetool|Merge]]) la PR a la branca principal.
6. Esborrar la branca.

## Diferència: Fork vs Clone
- **Cloning:** Fes una còpia local del repositori. Necessites permís d'escriptura per fer `push`.
- **Forking:** Fes una còpia del repositori al **teu compte de GitHub**. Pots treballar lliurement i després demanar al propietari original que accepti els teus canvis mitjançant una Pull Request.
