## `git revert` - desfer canvis sense reescriure l’historial

> [!NOTE] Important
> El comandament `git revert` desfa els canvis d’un [[./303.10.GIT - El Commit i Conventional Commits|commit]] **creant un commit nou** que aplica la inversa.
> **No reescriu l’historial**, així que és l’opció segura quan la [[./303.20.GIT - Conceptes Bàsics de Branca|branca]] ja s’ha compartit.

És útil quan:
- Has pujat commits al [[./303.40.GIT - Treball en Remot i Push|remot]] i vols "desfer" canvis sense fer [[./303.60.GIT - Reset|reset]].
- Treballes en una branca compartida (`main`, `develop`, etc.).
- Vols conservar un historial auditable (què s’ha fet i què s’ha desfet).
## Ús bàsic
### Revertir un commit concret

```bash
git revert <hash_del_commit>
```

Això crea un commit nou amb un missatge tipus "Revert …".

### Revertir l’últim commit

```bash
git revert HEAD
```

### Revertir diversos commits (un per un)

```bash
git revert <hash1> <hash2> <hash3>
```

## Revertir un rang de commits
Per revertir un conjunt de commits consecutius, Git permet especificar un rang.

Exemple: revertir els últims 3 commits (creant 3 reverts)

```bash
git revert HEAD~3..HEAD
```


> [!NOTE] Nota
> Això generarà **un commit de revert per cada commit** revertit.

## Evitar el commit automàtic (preparar abans de confirmar)

Si vols revisar/ajustar el revert abans de crear el commit:

```bash
git revert --no-commit <hash_del_commit>
```

- Aplica el revert al teu directori de treball.
- Et deixa decidir què incloure i quin missatge posar.
- Després fas `git commit` manualment.
## Revertir un [[./303.24.GIT - Merge i Mergetool|merge]] commit (cas especial)

Un merge té dos pares, així que cal indicar quin "camí" vols mantenir:

```bash
git revert -m 1 <hash_del_merge>
```

- `-m 1` vol dir "mantén el primer pare" (normalment la branca on estaves quan vas fer el merge).
- Si tries el pare equivocat, el resultat pot ser inesperat.

> [!warning] Perill
> Revertir merges és delicat: revisa bé el [[./303.31.GIT - Comparació amb Diff|diff]] abans de fer `push`.

## [[./303.25.GIT - Resolució de Conflictes en package-lock|Conflictes]] durant un revert

Si hi ha conflictes:
1. Resol els conflictes als fitxers.
2. Marca’ls com resolts:
   ```bash
   git add .
   ```
3. Continua el revert:
   ```bash
   git revert --continue
   ```
Si vols cancel·lar el revert en curs:
```bash
git revert --abort
```
