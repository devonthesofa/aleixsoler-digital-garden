# Git Diff
**Git Diff** és l'eina de visualització de diferències per excel·lència. T'ensenya línia per línia què has afegit (en verd amb un `+`) i què has eliminat (en vermell amb un `-`) entre diferents [[./303.06.GIT - Estats dels Fitxers|estats]] del teu repositori.

---
## Escenaris d'ús habituals
### 1. Canvis al Directori de Treball
Vols veure què has modificat des de l'última vegada que vas desar, però que **encara no has afegit al stage** (`git add`):
```bash
git diff
```
### 2. Canvis al Stage (Preparats per al [[./303.10.GIT - El Commit i Conventional Commits|commit]])
Si ja has fet `git add` d'alguns fitxers i vols revisar-los abans de fer el `git commit`:
```bash
git diff --staged
# O també:
git diff --cached
```
### 3. Comparar el Directori de Treball amb l'últim Commit
Per veure absolutament tots els canvis (estiguin al stage o no) respecte a l'últim punt de control:
```bash
git diff HEAD
```

---

## Comparacions entre [[./303.20.GIT - Conceptes Bàsics de Branca|Branques]] i Commits

| Objectiu                                   | Comandament                             |
| :----------------------------------------- | :-------------------------------------- |
| **Comparar dues branques**                 | `git diff branca-A..branca-B`           |
| **Comparar dos commits**                   | `git diff hash1..hash2`                 |
| **Diferències d'un fitxer concret**        | `git diff fitxer.txt`                   |
| **Diferències d'un fitxer entre branques** | `git diff branca-A..branca-B fitxer.js` |
|                                            |                                         |

---

## Opcions i Flags útils

* **`--stat`**: En lloc de veure tot el codi, mostra un resum de quins fitxers han canviat i quantes línies s'han tocat.
  ```bash
  git diff --stat
  ```
* **`-w` / `--ignore-all-space`**: Ignora els canvis que només siguin espais en blanc o tabulacions. Molt útil per netejar el diff de soroll visual.
* **`--color-words`**: En lloc de mostrar línies senceres, ressalta exactament quines paraules han canviat dins d'una línia.

---

## Entendre el flux de Diff

Per visualitzar on estàs comparant, recorda les tres zones de Git:
1.  **`git diff`**: Compara el *Working Directory* amb el *Staging Area*.
2.  **`git diff --staged`**: Compara el *Staging Area* amb el *Local Repository* (HEAD).
3.  **`git diff HEAD`**: Compara el *Working Directory* directament amb el *Local Repository*.
